Heat Hazard Index (HHI) Framework
This repository contains the Python scripts and Google Earth Engine (GEE) links used in the study:
Hung, F. et al. (2025). Urban Heat Risks Reimagined: A Framework for Global Physical Hazard Assessment.
The code implements the Heat Hazard Index (HHI) framework, which integrates land surface temperature (LST), urban heat island (UHI) intensity, and heatwave metrics to provide a transparent, globally scalable measure of urban heat hazards.

Google Earth Engine (GEE) Scripts
The following GEE scripts were used to extract and preprocess global datasets:
MODIS LST extraction: https://code.earthengine.google.com/3316e28ef2803e4cac878c61ff439cca
ERA5-Land variables for apparent temperature and heatwave metrics: https://code.earthengine.google.com/2e8a28bd8247fb2b443455bf8d4ebefc
YCEO urban extent dataset processing: https://code.earthengine.google.com/7f0c0cc5651b26093b5431258207e8fc
